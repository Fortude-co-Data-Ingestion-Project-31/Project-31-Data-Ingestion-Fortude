# Project Overview
Modern enterprises operate across a wide range of platforms ERP systems like Infor,  project management tools like JIRA, and collaboration platforms like SharePoint.  

Data generated by these systems is fragmented, stored in different formats and schemas,  and typically cannot be queried or analyzed in a unified way. 

The Data Ingestion Engine is designed to bridge this gap. It acts as a central pipeline that: 
• Connects to multiple source systems via dedicated connectors, 
• Extracts and normalizes data using a configurable mapper layer, 
• Applies domain-specific business rules to filter, enrich, or route records, and • Loads the processed data into appropriate target storage systems including a  Vector Database for AI/RAG workloads, a SQL Database for structured queries,  and a Document Database for schema-flexible storage.
